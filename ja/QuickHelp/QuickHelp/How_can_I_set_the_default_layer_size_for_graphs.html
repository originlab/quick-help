FAQ-1237 グラフのデフォルトレイヤサイズを設定するには?

Set-Default-Layer-Size

最終更新日：2026/1/26

グラフにカスタムレイヤ寸法を設定し、それをシステムテーマとして保存した場合、その設定が新しく作成されたグラフに適用されないことがあります。これは、グラフオプションダイアログがシステムテーマよりも優先され、テーマベースの設定が上書きされるためです。

カスタムレイヤサイズをデフォルトとして設定する方法

  1. メニューの環境設定：グラフオプション...を選択します。
  2. グラフオプションダイアログで、レイアウトタブに移動し、ページ余白(%)を自動に設定します。つまり、レイヤサイズ（余白）にシステムテーマを使用します。
  3. OKをクリックします。

すべての新しいグラフは、システムテーマで設定されたレイヤ寸法で作成されます。

キーワード:ページサイズ、レイヤサイズ、システムテーマ、デフォルトサイズ、グラフ幅、グラフの高さ
