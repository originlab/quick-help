FAQ-1220 特定のCRANミラーからRパッケージをデフォルトでダウンロードする方法

R-Packages-CRAN-Mirror

最終更新日：2025/6/20

Rは異なるCRANミラーからのRパッケージのダウンロードをサポートしています。

デフォルトのミラーが遅い場合、別のミラーをデフォルトとして設定することができます。

  1. メモ帳を管理者として実行（右クリックして[管理者として実行を選択）次のファイルを参照して開く
    C:\Program Files\R\R-4.5.0\etc\Rprofile.site
  2. set a CRAN mirror セクションを見つけて編集し、デフォルトのミラーを指定。例えば、 
    # CRANミラーを設定
 local({r <- getOption("repos")
        r["CRAN"] <- "https://mirrors.tuna.tsinghua.edu.cn/CRAN/"
        r["Mirror1"] <- "https://ftp.yz.yamagata-u.ac.jp/pub/cran/"
        r["Mirror2"] <- "https://ftp.fau.de/cran/"
        r["Mirror3"] <- "https://cran.yu.ac.kr/"
       options(repos=r)})

キーワード:R パッケージ, CRAN ミラー, install.packages(), リポジトリ
