FAQ-1206 現在のプロジェクト内の操作を全て再計算するには?

recalculate-all-operations-in-project

最終更新日：2024/10/23

現在のプロジェクト内のすべての操作(完了した操作と保留中の操作の両方)を強制的に再計算するには

  1. メニューからウィンドウ：スクリプトウィンドウ を選択します。
  2. 開いたスクリプトウィンドウで、次のrunコマンドを入力し、それらを強調表示してEnterキーを押して実行します。 
    run -auf 2 1; //現在のプロジェクト内のすべての操作
run -p au; //強制再計算

キーワード:再計算,分析レポート,更新レポート, テーブルスタイルの更新
