5.37 FAQ-738 如果 Origin 在 Mac 上的虚拟机中运行缓慢应该怎么办？

Virtual-Machine-is-Slow-on-Mac

Last Update: 11/13/2025


如果您的 Origin 在 Mac 上的虚拟机中运行缓慢，请考虑以下解决方案以提高性能。


调整虚拟机配置

您可以考虑根据 Windows 操作系统 (Vista/7/8/10/11)所推荐的系统配置来调整虚拟机的配置。

尤其要确保为虚拟机 (VM) 分配足够的 CPU 核心和内存来处理工作负载。


安装虚拟机工具

考虑安装虚拟机工具，例如 VMware、Parallels 等，以提高性能。

此外，您的虚拟机软件供应商可能会提供改进虚拟机性能的选项。请参阅供应商的文档来调整能帮助提高虚拟机性能的设置。


禁用更新或扫描

检查客户操作系统是否正在运行更新检查或磁盘病毒/威胁扫描。如果是，请考虑暂时禁用它们。


使用 Boot Camp

请考虑通过 Boot Camp 安装并运行 Windows 系统。这样可以确保 Windows 系统以原生速度运行，也就是说，Windows 应用程序可以充分利用 Mac 的硬件性能。


注: 如果您在 Mac 的虚拟机中运行 Windows，并且发现 Origin 运行开始变得缓慢，请尝试完全关闭 Windows（不仅仅是暂停），然后重新启动 Windows 并检查 Origin 的性能是否有所提高。
