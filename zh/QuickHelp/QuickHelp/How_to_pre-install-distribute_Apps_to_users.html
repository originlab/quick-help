6.108 FAQ-1194 如何向用户预安装/分发应用程序？

preinstall-apps

Last Update: 5/21/2025

注意：仅当终端用户启动 Origin 时才会安装应用程序，并且仅对该用户可见。

IT 部门参与安装 Origin 和分发应用程序的站点

  • IT 在 Origin 安装文件夹中创建一个名为 Auto Install 的文件夹 (带有 Setup.exe 或 MSI)
  • 下载应用程序文件 (*.opx) 并将其保存在 Auto Install 文件夹中
  • IT 使用系统管理员帐户在终端用户计算机上安装 Origin，并在安装过程中选择 "For all users（适用于所有用户）"。Auto Install文件夹将被复制到终端用户的 Origin 程序文件夹，比如 “C:\Program Files\OriginLab\Origin2025\Auto Install” (以 Origin 2025 举例)。IT 甚至可以在 Origin 安装完成后向此文件夹添加更多 opx 文件。注意：此时应用程序尚未安装。
  • 当终端用户登录计算机并启动 Origin 时，系统会自动为该用户帐户安装 Auto Install 文件夹下的所有应用程序。这里可能会发生不同的事情
    • A. 大多数应用程序会静默安装到 C:\Users\<用户名>\AppData\Local\OriginLab\Apps\，因为终端用户应该拥有该文件夹的写入权限。
    • B. 某些应用程序需要 Python 软件包（例如：Neural Network Regression/神经网络回归）。终端用户会看到提示安装 Python 软件包的注意消息。点击“是”即可安装 Python 软件包，其余情况与 A 相同。
    • C. 某些应用程序需要第三方软件（例如 DOE 需要 R 软件）。如果找不到 R 软件，终端用户将被要求以管理员身份运行 Origin 以先安装 R。

向已安装 Origin 的终端用户分发应用程序

  • 设定组长和成员
    1. 第一步是为组长机器设置组文件夹。
    2. 接下来，为成员机器设置组文件夹。
  • 分发应用程序
    1. 在组长机器上的用户文件夹创建一个名为 Auto Install 的文件夹
    2. 下载应用程序文件 (*.opx) 并保存在 Auto Install 文件夹
    3. 使用组文件夹管理器分发应用程序文件 (*.opx)
    4. 当 Origin 组成员启动 Origin 时，将看到安装在 Origin 上的应用程序
