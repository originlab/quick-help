6.113 FAQ-1210 我在运行 Install Shield 设置 Origin 时看到错误 (-5001:0x80070002)时该怎么办？

InstallShield-Error-Finish-Previous-Setup

 

Last Update: 5/21/2025


当运行 Origin 安装程序 Setup.exe 来安装 Origin 时，看到以下错误消息：

运行安装程序时出现错误 (-5001: 0x80070002)。

请确保您已完成所有先前的设置并关闭了其他应用程序。 如果错误仍然存​​在，请联系您的供应商：

这个问题很可能出现在没有解压就从 zip 文件运行 setup.exe。


要解决这个问题，

在运行 Setup.exe 之前，请确保已完成下载 zip 文件并将文件解压到本地磁盘。
