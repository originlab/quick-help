6.110 FAQ-1198 网络版许可证用户如何知道在特定时间内谁占用了许可证？

Perform-License-Status-Enquiry-on-Client

Last Update: 10/24/2024

网络版许可证类型意味着购买的许可证数量在客户端之间浮动分配。如果您使用的是网络版许可证，有时，尤其是当所有可用许可证都被占用时，您可能希望查看当时谁正在退出使用许可证。

作为网络版许可证的管理员，您随时可以打开 LMTools 并在 Server Status 选项卡上Perform Status Enquiry。在输出文本的末段，您可以找到许可证签出状态。

作为客户端，您可以选择以下方式之一从客户端电脑查询许可证状态。

方法1

  1. 复制 LMTools.exe 到客户端电脑。
  2. 打开 LMTOOLS 点选 Service/License File 选项卡。
  3. 选择 Configuration using License File 选项按钮。
  4. 输入
    @SERVERNAME or @IP_Address_Of_Server
    进编辑框，其中 SERVERNAME 是你的许可证服务器名，要确保名字前面带有 “@” 。譬如，假设你的服务器名为 “OriginServer”，应当如此输入：
  5. 在 Server Status 选项卡点击 Perform Status Enquiry 按钮，输出服务器状态将显示当前哪些客户端占用了许可证。

方法2

  1. 复制 lmstat.exe 到客户端电脑。您可在许可证管理器文件夹下的 \Tools\command line 文件夹找到这执行文件。
  2. 打开文本编辑器 (如记事本)输入以下命令行，并保存为一个 .bat 文件。 
    @echo off 
<path_to_lmstat.exe>\lmstat.exe -a -c <port_no.>@SERVERNAME 
pause


    其中<path_to_lmstat.exe> 是指向客户端电脑中 lmstat.exe 文件的路径，SERVERNAME 是你的许可证服务器名。port_no. 是 lmgrd.exe 使用的端口号。 这个可以被省略如果使用的是默认端口 27000，但必须带有 "@"。譬如，假设你复制 lmstat.exe 文件到文件夹 C:\Tools\OriginLicenseServer\command line\，你的许可证服务器名为 “OriginServer” 端口为 27001，向 .bat 文件输入以下命令： 

    @echo off 
"C:\Tools\OriginLicenseServer\command line\lmstat.exe"  -a -c 27001@OriginServer
pause
  3. 你随时可以双击 .bat 文件查看状态。
