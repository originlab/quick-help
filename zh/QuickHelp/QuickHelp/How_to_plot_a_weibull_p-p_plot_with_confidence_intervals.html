3.91 FAQ-329 如何绘制带有置信带的概率图？

Plot-weibull-P-P-Plot

Last Update: 12/13/2025

如果想绘制有置信带的概率图，我们可以

  1. 选择菜单 绘图 > 统计图: 概率图
  2. 在打开的对话框中， 确认 置信带 选项被选中


又或者，可以使用 分布拟合 工具（从菜单 统计: 描述统计: 分布拟合 打开）绘制带有置信带的概率图（p-p plot）


无论哪种方法， 都支持以下几种分布

正态 Normal 指数 Exponential 伽玛 Gamma Log-logistic
对数正态 LogNormal 双参数指数 2-Parameter Exponential 最小极值 Smallest Extreme Value Gaussian
3参数对数正态 3-Parameter-Lognormal 威布尔 Weibull 最大极值 Largest Extreme Value 折叠正态 Folded Normal
3参数威布尔 3-Parameter Weibull Logistic Rayleigh
