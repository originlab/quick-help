4.75 FAQ-1220 如何默认从指定的 CRAN 镜像下载 R 包？

R-Packages-CRAN-Mirror

Last Update: 11/12/2025

R 可以从不同的 CRAN 镜像下载 R 包。

如果默认镜像速度慢，可以改用其他镜像作为默认:

  1. 以管理员身份运行记事本（右击并选择以管理员身份运行）。浏览并打开以下文件:
    C:\Program Files\R\R-4.5.0\etc\Rprofile.site
  2. 找到 set a CRAN mirror 章节去修改默认镜像，比如: 
    # set a CRAN mirror
 local({r <- getOption("repos")
	r["CRAN"] <- "https://mirrors.tuna.tsinghua.edu.cn/CRAN/"
	r["Mirror1"] <- "https://ftp.yz.yamagata-u.ac.jp/pub/cran/"
	r["Mirror2"] <- "https://ftp.fau.de/cran/"
	r["Mirror3"] <- "https://cran.yu.ac.kr/"
       options(repos=r)})
