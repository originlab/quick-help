4.74 FAQ-1214 当 Origin 无法启动 R 时，怎么办？

Origin-has-trouble-launching-R

Last Update: 5/24/2025

如果 Origin 尝试启动 R 时遇到以下问题

尝试启动 R 时 Origin 崩溃并弹出如下警告消息


尽管计算机上安装了较新版本的 R，Origin 仍启动旧版本的 R

解决方法

这是因为您在 Windows 注册表中设置了一个名为 R_HOME 的 Windows 环境变量。请按照以下说明删除该变量。

  1. 如果 Origin 正在运行，请退出。
  2. 在 Windows 搜索中，搜索高级系统设置（不带引号），然后打开查看高级系统设置（控制面板）。
  3. 在系统属性对话框中，选择高级选项卡。
  4. 点击环境变量...按钮。
  5. 从用户变量或系统变量中删除 R_HOME。
