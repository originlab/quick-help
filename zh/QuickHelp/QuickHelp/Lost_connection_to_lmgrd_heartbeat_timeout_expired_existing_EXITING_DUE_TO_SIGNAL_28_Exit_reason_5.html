6.109 FAQ-1197 我看到“Lost connection to lmgrd, heartbeat timeout expired, existing. EXITING DUE TO SIGNAL 28 Exit reason 5”这样的错误信息，应该怎么解决？

Lost-Connection-to-Lmgrd

Last Update: 10/25/2024

如果您启动 FLEXnet 许可证服务失败并在日志文件中看到以下错误消息：

10:38:30 (lmgrd) Lost connection to lmgrd, heartbeat timeout expired, exiting.
10:38:30 (lmgrd) Heartbeat timeout is 300 seconds. Elapsed time is 16528 seconds.
10:38:30 (lmgrd) EXITING DUE TO SIGNAL 28 Exit reason 5
10:38:30 (lmgrd) orglab exited with status 28 (Communications error)


连接断开可能是由服务器和客户端之间的防火墙引起的。
如何解决这个问题：

请根据此文档使许可证服务器通过防火墙访问。

注意，在第一步 “At the Firewall”，当打开指定端口时，请确保对可能中断服务器和客户端连接的每个防火墙都这样做。例如，在服务器电脑上，除了 Windows 内置防火墙，电脑上安装的病毒软件可能还建了一个防火墙。在这种情况下，需要在两个防火墙中关闭指定端口的监控。
