6.112 FAQ-1205 启动Origin遇到这样的错误“The installed version of the application could not be determined. The setup will be now terminate”，该怎么办？

Installed-Version-not-be-Determined

Last Update: 10/25/2024

当运行Origin安装程序setup.exe时遇到以下错误：

The installed version of the application could not be determined. The setup will now terminate.

这是因为没有管理员权限造成的。


要解决这个问题：

请使用管理员帐户登录系统，或以管理员身份运行setup.exe文件（右击setup.exe并在菜单选择以管理员身份运行）。

Keywords:installation, 安装, setup, log in account, 登录账号
