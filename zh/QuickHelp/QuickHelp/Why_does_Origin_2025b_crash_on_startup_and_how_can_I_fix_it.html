5.93 FAQ-1228 我的 Origin 2025b 每次启动都会崩溃，该怎么办？

Origin-Crash-on-Startup

Last Update: 12/14/2025

我们收到多份报告，指出 Origin 的最新三个版本（2024b、2025和2025b）在启动时容易崩溃。根源在新版的 Microsoft Visual C++ 可再发行组件包。事实上，这是一个全球性问题，详情请见此处。

如果您的 Origin 每次启动都崩溃，请先检查您电脑上的 Microsoft Visual C++ 可再发行组件包是否存在问题：

  1. 搜索并打开 Windows 控制面板，选择 程序 > 程序和功能


  2. 在列表中找寻 "Microsoft Visual C++ … - 14.###". 如果版本号 ### 是 50.35710 或更低，则表示该版本基于 2017-2026，并且存在问题。

如何修复

  • 请下载安装 最新的 Microsoft Visual C++ 可再发行组件包 去永久解决这问题：
    • X86
    • X64
  • 如果您不想更新可再发行组件包，请将 Origin 升级到 2026 或更高版本。Origin 2026 包含其自身的解决方案，无需微软的修复程序。
