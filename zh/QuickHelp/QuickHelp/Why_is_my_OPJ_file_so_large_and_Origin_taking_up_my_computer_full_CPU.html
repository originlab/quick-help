5.30 FAQ-710 为什么生成的 OPJ 文件特别大并且 Origin 会使计算机 CPU 满载？

OPJ-so-large-and-take-full-cpu

Last Update: 10/29/2024

如果您遇到了这些问题：

  • 当您正在使用某个 Origin 项目文件（OPJ）时，Origin 使计算机的 CPU 满载。
  • OPJ 文件非常大。
  • 当您点击黄色的 Recalculate 工具栏按钮时，重新计算失败并且按钮变为红色。

这些问题可能是因为

未响应的操作

要解决此问题，请执行以下步骤来删除未响应的操作。

打开目标 OPJ 文件，然后打开 脚本窗口 (窗口:脚本窗口)，输入以下脚本并按下 ENTER 键。那么 Origin 将在 脚本窗口 中列出所有的操作，其中未响应的操作是没有输入和输出的。 

list op;

然后输入以下脚本（并按下 ENTER 键）来删除这些未响应的操作从而解决 OPJ 的问题。 

delete -op;

重新保存项目文件。

自动填充范围

在旧版本中，当用户自动填充工作表某些范围时，这范围可能被错误地增加了。 要检测这种情况，打开目标 OPJ 文件，在 脚本窗口 (窗口:脚本窗口)，输入以下脚本并按下 ENTER 键。 

doc.rangescount(32)=

如果输出的是大数字，运行以下脚本去删除所有自动填充范围 

del -r 32

重新保存项目文件。

Keywords:large OPJ, full CPU, Recalculate fails, 大 OPJ， CPU 满载， 重新计算失败

Minimum Origin Version Required: 8.5.1
