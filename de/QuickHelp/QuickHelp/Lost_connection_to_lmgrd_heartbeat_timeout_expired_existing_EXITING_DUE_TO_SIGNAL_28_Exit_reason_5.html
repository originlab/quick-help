FAQ-1197 Ich erhalten den Fehler "Verbindung zu lmgrd verlorengegangen, Heartbeat-Zeitlimit abgelaufen, existiert. WIRD AUFGRUND VON SIGNAL 28 BEENDET Grund 5". Was soll ich tun?

Lost-Connection-to-Lmgrd

Letztes Update: 05.09.2024

Wenn das Starten des FLEXnet-Lizenzservers fehlschlägt und Sie die folgende Fehlermeldung in der Log-Datei erhalten:

10:38:30 (lmgrd) Lost connection to lmgrd, heartbeat timeout expired, exiting.
10:38:30 (lmgrd) Heartbeat timeout is 300 seconds. Elapsed time is 16528 seconds.
10:38:30 (lmgrd) EXITING DUE TO SIGNAL 28 Exit reason 5
10:38:30 (lmgrd) orglab exited with status 28 (Communications error)


Diese Fehlverbindung wird wahrscheinlich durch eine Firewall zwischen Server und Clients verursacht.
Um dieses Problem zu beheben:

Bitte lesen Sie dieses Dokument, um Ihrem Lizenzserver Zugriff durch die Firewall zu gewähren.

Beachten Sie, dass in Schritt 1 “An der Firewall”: Wenn Sie bestimmte Ports öffnen, stellen Sie sicher, dass Sie das für jede Firewall machen, die die Verbindung zwischen Server und Clients unterbrechen könnte. Zum Beispiel kann auf dem Server neben der Standardfirewall von Windows auch die auf dem Rechner installierte Antivirensoftware eine weitere Firewall errichten. In diesem Fall müssen Sie die Überwachung bestimmter Ports in beiden Firewalls abschalten.

Schlüsselwörter:Concurrent, -15, 10032, lmgrd wird nicht ausgeführt, kann keine Verbindung zum Lizenzserver herstellen, Port oder Hostname wurden in der Lizenzdatei geändert, WIRD AUFGRUND VON SIGNAL 28 BEENDET, Grund 5, EXITING DUE TO SIGNAL 28, Exit reason 5, Orglab beendete mit Status 28, Kommunikationsfehler, verlorene Verbindung zu lmgrd, Heartbeat-Zeitlimit abgelaufen
