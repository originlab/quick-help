FAQ-474 Wie kann ich Text in zusammengefügten Zellen bearbeiten und formatieren?

Customize-Text-in-MergedCells

Letztes Update: 02.02.2026

Origin bietet zwei Möglichkeiten, nebeneinanderliegende Zellen in einem beliebigen Bereich des Arbeitsblatts zusammenzufügen (sowohl Headerzeilen als auch Datenbereich). Jede Methode verhält sich leicht unterschiedlich, wenn Sie den Inhalt bearbeiten oder formatieren.

  • Dynamisch zusammenfügen
    • Klicken Sie auf die Schaltfläche Dynamisch zusammenfügen auf der Minisymbolleiste, wenn ein Zellenblock ausgewählt ist.
    ODER
    • Wählen Sie im Menü Format: Arbeitsblatt, um den Dialog Arbeitsblatteigenschaften zu öffnen. Bearbeiten Sie auf der Registerkarte Format die Listen Anwenden auf (Headerzeilen oder Datenbereich) und Dynamisch zusammenfügen (Horizontal, Vertikal oder Beides). Sie können auch den Bereich auswählen, den Sie dynamisch zusammenfügen möchten, klicken Sie mit der rechten Maustaste und wählen Sie Zellen formatieren und aktivieren Sie Dynamisch zusammenfügen.
    Bearbeiten oder Formatieren
    • Wenn Sie Zellen dynamisch zusammenfügen, behalten die einzelnen Zellen weiterhin ihren ursprünglichen Inhalt. Das einmalige Klicken auf den zusammengefügten Block wählt den gesamten Block aus. Sie können jetzt direkt den Typ eingeben, um alle Zellen auf einmal zu überschreiben (oder klicken Sie doppelt, um den direkten Bearbeitungsmodus aufzurufen).
    • Das zweimalige Klicken auf den Block wählt die einzelne Zelle aus. Sie können jetzt diese einzelne Zelle bearbeiten (oder klicken Sie doppelt, um den direkten Bearbeitungsmodus aufzurufen). Beachten Sie, dass das Ändern der aktiven Zelle das Zusammenfügen aufheben wird ...

  • Statisch zusammenfügen
    • Wählen Sie den Bereich aus, den Sie zusammenfügen möchten, und klicken Sie auf die Schaltfläche Zellen zusammenfügen auf der Symbolleiste Stil.
    Bearbeiten oder Formatieren
    • Durch diese Methode des Zusammenfügens wird nur Inhalt in der oberen linken Zelle gezeigt. Die einzelnen Zellen behalten ihren ursprünglichen Inhalt bei. Wenn Sie den zusammengefügten Block auswählen (durch Einzel- oder Doppelklick) und ihn bearbeiten, wird nur die erste Zelle geändert.
    • Um alle Zellen im Block zu aktualisieren, müssen Sie den Block wieder auflösen, indem Sie auf die Schaltfäche Zellen zusammenfügen klicken. Wählen Sie dann den gesamten Bereich, geben Sie den neuen Text ein und drücken Sie die Tasten Strg + Enter. Alle ausgewählten Zellen werden modifiziert. Sie können sie erneut zusammenfügen.
