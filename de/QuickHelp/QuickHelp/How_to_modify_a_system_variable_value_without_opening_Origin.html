FAQ-1234 Wie ändere ich den Wert einer Systemvariablen, ohne Origin zu öffnen?

Change-System-Variables-without-Origin-Open

Letztes Update: 25.12.2025

Wenn Origin normal gestartete wird, können Sie immer den Dialog Systemvariablen festlegen verwenden, um einen Variablenwert zu ändern. Wenn Origin aus irgendeinem Grund jedoch nicht gestartet wird und Sie eine Systemvariable anpassen müssen, um das Problem zu beheben, finden Sie die Schritte hier im Folgenden.

  • Für registry-basierte Systemvariablen:
    Öffnen Sie den Registry Editor, erweitern Sie den Zweig \HKEY_CURRENT_USER\Software\OriginLab\SysVar und bearbeiten oder fügen Sie die gewünschten Werte direkt hinzu.
  • Für Nicht-Registry-Systemvariablen:
    1. Stellen Sie sicher, das kein Origin-Prozess läuft.
    2. Öffnen Sie SystemVariables.ogs im Anwenderdateiordner mit dem Notepad-Editor (erstellen Sie die Datei, falls sie nicht existiert). Fügen Sie die Variable in der [Main]-Session ein. Wenn Sie z. B. @PESS in -1 ändern möchten, fügen Sie den unten stehenden Text hinzu:
      [Main] @PESS=-1;

      Speichern Sie die Datei.

      • Wenn Sie SystemVariables.ogs in Schritt 2 erstellt haben, öffnen Sie Origin.ini im Anwenderdateiordner mit Notepad und fügen Sie folgenden Schlüssel in die [Startup]-Session ein.
        [Startup] sysvar=SystemVariables.ogs
        Speichern Sie die Datei.
    3. Starten Sie Origin erneut. Prüfen Sie, ob es normal gestartet werden kann.
