FAQ-1206 Wie werden alle Operationen im aktuellen Projekt neu berechnet?

recalculate-all-operations-in-project

Letztes Update: 23.10.2024

Um die Neuberechnung aller Operationen im aktuellen Projekt zu forcieren (sowohl fertige und ausstehende):,

  1. Wählen Sie im Menü Fenster: Skriptfenster.
  2. Geben Sie im geöffneten Skriptfenster folgende run-Befehle ein, markieren Sie sie und drücken Sie Enter, um sie auszuführen: 
    run -auf 2 1; //dirty all operations in the current project run -p au; //force recalculation

Schlüsselwörter:neu berechnen, Analysebericht, Bericht aktualisieren, Tabellenstil aktualisieren
