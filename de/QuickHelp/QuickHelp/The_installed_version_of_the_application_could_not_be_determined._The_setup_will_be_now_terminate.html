FAQ-1205 Beim Installieren von Origin wird mir die Fehlermeldung “Die installierte Version der Anwendung konnte nicht bestimmt werden. Die Installation wird jetzt beendet.” angezeigt. Was soll ich tun?

Installed-Version-not-be-Determined

Letztes Update: 05.09.2024

Wenn Sie das Origin-Installationsprogramm setup.exe ausführen, um Origin zu installieren, Ihnen aber folgende Fehlermeldung angezeigt wird:

Die installierte Version der Anwendung konnte nicht bestimmt werden. Die Installation wird jetzt beendet.

Sie wird durch fehlende Administratorrechte verursacht.


Um dieses Problem zu beheben:

Bitte melden Sie sich über einen Administratorkonto am System an oder führen Sie die Datei setup.exe als Administrator aus (Rechtsklick auf setup.exe und Auswahl von Als Administrator ausführen im Kontextmenü).

Schlüsselwörter:Installation, Setup, Anmeldekonto
