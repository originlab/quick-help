FAQ-1241 Warum kann ich Apps bzw. Vorlagen in Origin nicht mit Windows 7 herunterladen?

Win7-Cannot-Download-App-Template

Letztes Update: 13.09.2026

Wenn Sie Origin auf Windows 7 ausführen, können Sie keine Apps mehr aus dem Apps-Center oder Vorlagen aus dem Vorlagencenter herunterladen. Da Windows 7 ein veraltetes Betriebssystem ist, das von Microsoft nicht mehr aktualisiert wird, und aufgrund von Sicherheitsbedenken, unterstützt die Webseite von OriginLab Windows 7 nicht mehr.

Um gewünschte Apps oder Vorlagen zu installieren:

  • Laden Sie das Installationsprogramm von der Webseite Dateiaustausch herunter und ziehen Sie es per Drag&Drop in den Origin-Arbeitsbereich, um App bzw. Vorlage zu installieren.


Hinweis: Die folgenden Funktionen und Werkzeuge sind ebenfalls nicht unter Windows 7 verfügbar:

  • Systemhinweise (z. B. Benachrichtigungen zu neuen Releases und Funktionen)
  • Nach Updates suchen
    Sie können noch immer ein Upgrade auf ein neues Service Release durchführen, indem Sie das Patch manuell von unserer Webseite herunterladen.
  • Lizenz online aktivieren
    Sie können die Aktivierung noch immer abschließen, indem Sie manuell die URL der Aktivierung kopieren und sie in einem Webbrowser öffnen.
