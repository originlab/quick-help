FAQ-1238 Gibt es eine Möglichkeit, wie ich die Einstellungen im Dialog Grafikoptionen speichern oder teilen kann?

Save-or-Share-Graph-Options-Settings

Letztes Update: 26.01.2026

Wenn Sie im Dialog Grafikoptionen benutzerdefinierte Einstellungen festlegen (Einstellungen: Grafikoptionen) und die Einstellungen speichern oder mit anderen teilen wollen, verwenden Sie bitte GraphOptions.oth im Anwenderdateiordner. Das heißt:

  1. Wählen Sie im Menü Hilfe: Ordner öffnen: Anwenderdateiordner.
  2. Gehen Sie zum Unterordner "Themes". Hier können Sie die Datei GraphOptions.oth finden, in der die Einstellungen des Dialogs Grafikoptionen gespeichert werden.
  3. Um die gleichen Standardeinstellungen auf einem anderen PC anzuwenden, legen Sie die Datei GraphOptions.oth im Unterordner \User Files\Themes\ des Zielrechners ab bzw. ersetzen Sie sie und starten Sie Origin neu.

Schlüsselwörter:Diagrammstandardeinstellungen, benutzerdefinierte Anpassungsdesigns, Diagrammstandard teilen, Grafikoptionen
