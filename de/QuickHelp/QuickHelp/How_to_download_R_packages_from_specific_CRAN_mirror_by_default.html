FAQ-1220 Wie lade ich R-Pakete standardmäßig von einem spezifischen CRAN-Mirror herunter?

R-Packages-CRAN-Mirror

Letztes Update: 20.06.2025

R unterstützt den Download von R-Paketen aus unterschiedlichen CRAN-Mirrorn.

Falls der Standard-Mirror langsam ist, können Sie einen anderen Mirror zum Standard machen:

  1. Führen Sie Notepad als Administrator aus (Rechtsklick und Auswahl von Als Administrator ausführen). Navigieren Sie zu und öffnen Sie die folgende Datei:
    C:\Program Files\R\R-4.5.0\etc\Rprofile.site
  2. Finden und bearbeiten Sie den Abschnitt set a CRAN mirror, um die Standardspiegel festzulegen. Zum Beispiel: 
    # set a CRAN mirror local({r <- getOption("repos") r["CRAN"] <- "https://mirrors.tuna.tsinghua.edu.cn/CRAN/" r["Mirror1"] <- "https://ftp.yz.yamagata-u.ac.jp/pub/cran/" r["Mirror2"] <- "https://ftp.fau.de/cran/" r["Mirror3"] <- "https://cran.yu.ac.kr/" options(repos=r)})

Schlüsselwörter:R-Paket, CRAN-Mirror, install.packages(), Repository
