FAQ-1194 Wie installiere ich Apps für die Benutzer vor bzw. verteile sie?

preinstall-apps

Letztes Update: 03.12.2024


Hinweis: Apps werden nur installiert, wenn der Endbenutzer Origin öffnet, und sind auch nur für diesen Anwender sichtbar.

Für Standorte, an denen die IT in die Installation von Origin und Verteilung von Apps involviert ist

  • Die IT erstellt einen Ordner mit dem Namen Auto Install im Installationsordner von Origin (mit Setup.exe oder MSI).
  • Die Apps-Dateien (*.opx) werden heruntergeladen und im Ordner Auto Install gespeichert.
  • Die IT installiert Origin auf dem Computer des Endbenutzers mit dem Account des Systemadministrators und wählt "Für alle Benutzer" während der Installation. Der Ordner Auto Install mit den Apps wird in den Origin-Programmordner des Endbenutzers kopiert, z. B. “C:\Program Files\OriginLab\Origin2025\Auto Install” (für Version 2025). Die IT kann sogar weitere opx-Dateien zu diesem Programmordner hinzufügen, nachdem Origin installiert ist. Hinweis: Zu diesem Zeitpunkt sind die Apps noch nicht installiert.
  • Wenn ein Endbenutzer sich an seinem Computer anmeldet und Origin öffnet, fängt die Installation aller Apps im Ordner Auto Install automatisch an. Hier passieren verschiedene Dinge.
    • A. Die meisten Apps werden stumm unter C:\Users\<username>\AppData\Local\OriginLab\Apps\ installiert, da der Endbenutzer die Zugriffsrechte auf diesen Ordner haben sollte.
    • B. Einige Apps erfordern Python-Pakete (z. B. Neural Network Regression). Der Endbenutzer sieht die Warnmeldung zum Installieren der Python-Pakete. Klicken Sie auf Ja, um die Python-Pakete zu installieren. Der Rest entspricht Fall A.
    • C. Einige Apps erfordern eine Drittanbietersoftware (z. B. erfordert DOE die Software R). Der Endbenutzer wird aufgefordert, Origin als Administrator auszuführen, um zuerst R zu installieren, falls die Software R nicht gefunden werden konnte.

Die Apps im Nachhinein an Endbenutzer verteilen, die Origin bereits installiert hatten

  • Gruppenleiter und Gruppenmitglieder einrichten
    1. Der erste Schritt ist, den Gruppenordner für den Rechner des Gruppenleiters einzurichten.
    2. Als Nächstes kann der Gruppenordner für die Rechner der Mitglieder eingerichtet werden.
  • Die Apps verteilen
    1. Erstellen Sie einen Ordner mit dem Namen Auto Install im Anwenderdateiordner auf dem Gruppenleiterrechner.
    2. die Apps-Dateien (*.opx) herunteraden und sie im Ordner Auto Install speichern.
    3. Verwenden Sie Gruppenordner verwalten, um die Apps-Dateien (*.opx) zu verteilen.
    4. Wenn die Origin-Gruppenmitglieder jetzt ihr Origin starten, finden Sie die Apps bereits in ihrem Origin installiert.
