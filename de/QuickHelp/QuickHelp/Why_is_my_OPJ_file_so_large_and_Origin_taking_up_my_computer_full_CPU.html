FAQ-710 Warum ist meine OPJ-Datei so groß, und warum nimmt Origin die gesamte CPU meines Computers in Beschlag?

OPJ-so-large-and-take-full-cpu

Letztes Update: 12.08.2024

Wenn Sie eines dieser Probleme erleben:

  • Sie arbeiten mit einer spezifischen Origin-Projektdatei (OPJ), und Origin nimmt die gesamte CPU des Computers in Beschlag.
  • Die Größe einer OPJ-Datei ist unverhältnismäßig groß.
  • Wenn Sie auf die Symbolleistenschaltfläche mit dem gelben Rechteck klicken, schlägt die Neuberechnung fehl und die Schaltfläche wird rot.

Diese Probleme werden womöglich verursacht von:

Ausstehende Operationen

Führen Sie die untenstehenden Schritte durch, um die ausstehenden Operationen zu löschen. Öffnen Sie die spezifische OPJ. Rufen Sie dann das Skriptfenster auf (Fenster: Skriptfenster), geben Sie das folgende Skript ein und drücken Sie Enter. Origin listet die Operationen im Skriptfenster auf. (Ausstehende Operationen sind Operationen ohne Eingabe und Ausgabe.)

list op

Geben Sie dann das folgende Skript ein (und drücken Sie Enter), um diese ausstehenden Operationen zu löschen:

delete -op

Speichern Sie das Projekt neu.

Autofill Ranges - automatisch gefüllte Bereiche

Wenn Benutzer in alten Versionen Bereiche im Arbeitsblatt automatisch mit Daten füllen, kann es passieren, dass der Bereich fälschlicherweise vergrößert wird. Um zu prüfen, ob das der Fall ist, öffnen Sie das bestimmte OPJ und geben Sie im Skriptfenster folgendes Skript ein und drücken Sie ENTER.

doc.rangescount(32)=

Wenn eine große Zahl ausgegeben wird, führen Sie das folgende Skript aus, um alle automatisch gefüllten Bereiche zu entfernen.

del -r 32

Speichern Sie das Projekt neu.
