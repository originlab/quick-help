FAQ-1200 What happens if I open an OriginPro Project in Standard Origin?

Open-OriginPro-Project-Standard-Origin

Last Update: 8/9/2024

When an OriginPro project file is opened in Standard Origin, it can still be viewed normally. However, any (OriginPro Only) analyses operations will be locked with a gray lock icon and cannot be recalculated.

For other types of recalculation locks, see: Recalculating Analysis Results

Additionally, some graphs, such as Sankey diagrams, have customization options exclusive to OriginPro. While these customizations will be visible in Standard Origin, the options will be grayed out and uneditable.
