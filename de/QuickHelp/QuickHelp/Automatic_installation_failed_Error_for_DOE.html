FAQ-1242 Wie behebe ich den Fehler "Automatische Installation fehlgeschlagen" für die App Design of Experiments?

DOE-R-installation-failure

Letztes Update: 29.09.2026


  1. Stellen Sie sicher, dass die Software R auf Ihrem Computer installiert ist (empfohlene Version: 4.4.1).
  2. Klicken Sie auf das Symbol Design of Experiments in der Apps-Galerie.
  3. Die erforderlichen Pakete werden automatisch heruntergeladen. Falls der automatische Download fehlschlägt, wird die folgende Fehlermeldung im Ergebnisprotokoll angezeigt:
  1. Öffnen Sie R, kopieren Sie die letzten zwei Codezeilen aus dem Ergebnisprotokoll, fügen Sie sie in die R-Konsole und drücken Sie Enter, um sie auszuführen:
  1. Ein Dialogfenster fordert Sie auf, eine CRAN Mirror Site auszuwählen. Wählen Sie eine Site aus, um die Paketdownloads in R zu starten.
  2. Sobald der Download der Pakete ohne weitere Fehlermeldungen beendet ist, starten Sie Origin erneut.

Schlüsselwörter:DOE, CRAN Mirror auswählen, DOEOOR.R, InstallDOEPackages
