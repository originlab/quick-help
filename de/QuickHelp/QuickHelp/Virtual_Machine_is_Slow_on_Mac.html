FAQ-738 Was kann ich tun, wenn Origin auf der virtuellen Maschine eines Mac langsam läuft?

Virtual-Machine-is-Slow-on-Mac

Letztes Update: 18.08.2025

 

Sollte Ihr Origin auf einer virtuellen Maschine auf einem Mac langsam laufen, dann ziehen Sie bitte die folgenden Lösungen in Betracht, um die Leistung zu verbessern.

Konfiguration der VM anpassen

Sie können die Konfiguration der virtuellen Maschine entsprechend der empfohlenen Systemanforderungen des Windows-Betriebssystems (Vista/7/8/10/11) anpassen.

Stellen Sie insbesondere sicher, dass der virtuellen Maschine (VM) ausreichend CPU-Kerne und Speicher zugewiesen sind, um der Arbeitslast gerecht zu werden.

Werkzeuge der virtuellen Maschine installieren

Sie können Werkzeuge der virtuellen Maschine, wie Vmware und Parallels, installieren, um die Leistung zu verbessern.

Möglicherweise kann der Hersteller Ihrer virtuellen Maschine ebenfalls Optionen bereitstellen, die die Leistung der VM verbessern. Bitte ziehen Sie die Dokumentation des Herstellers zurate, um zu bestimmen, welche Einstellungen die Leistung verbessern könnten.

Updates bzw. Scans, die übermäßig viele Ressourcen brauchen, deaktivieren

Überprüfen Sie, ob ein Gastbetriebssystem Aktualisierungsprüfungen oder Viren-/Bedrohungsscans auf der Festplatte durchführt. Falls ja, überlegen Sie, diese temporär zu deaktivieren.

 

Boot Camp verwenden

Bitte ziehen Sie in Betracht, Windows über Boot Camp zu installieren und auszuführen. Dies ermöglicht Ihnen, Windows bei nativer Geschwindigkeit auszuführen, d.h., Windows-Applikationen können die Möglichkeiten der Mac-Hardware vollständig nutzen.

 

Hinweis: Wenn Sie denken, dass die Ausführung von Origin anfängt, langsam zu werden, während es in Windows auf einer virtuellen Maschine auf einem Mac läuft, versuchen Sie Windows vollständig herunterzufahren (nicht nur sperren). Starten Sie Windows neu und überprüfen Sie Origins Leistung.
