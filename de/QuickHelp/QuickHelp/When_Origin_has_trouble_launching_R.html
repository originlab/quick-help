FAQ-1214 Was kann ich tun, wenn Origin Schwierigkeiten hat, R zu starten?

Origin-has-trouble-launching-R

Letztes Update: 11.03.2025

Wenn Sie auf folgende Probleme stoßen, wenn Origin versucht, R zu starten:

Origin stürzt ab, wenn Sie versuchen, R zu starten, und es wird die folgende Warnmeldung angezeigt.


Origin startet eine alte Version von R, obwohl Sie eine neuere Version von R auf Ihrem Computer installiert haben.

Lösung

Der Grund hierfür ist, dass Sie eine Umgebungsvariable von Windows namens R_HOME in Ihrem Windows Registry festgelegt haben. Bitte befolgen Sie die Anweisungen, um die Variable zu löschen.

  1. Schließen Sie Origin, falls es gerade ausgeführt wird.
  2. Suchen Sie über die Windows-Suche nach den "erweiterten Systemeinstellungen" (ohne Anführungszeichen) und öffnen Sie Erweiterte Systemeinstellungen anzeigen (Systemsteuerung).
  3. Wählen Sie im Dialog Systemeigenschaften die Registerkarte Erweitert.
  4. Klicken Sie auf die Schaltfläche Umgebungsvariablen....
  5. Entfernen Sie R_HOME entweder aus den Benutzervariablen oder Systemvariablen.
