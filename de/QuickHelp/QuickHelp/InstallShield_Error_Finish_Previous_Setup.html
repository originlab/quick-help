FAQ-1210 Ich sehe einen Fehler (-5001:0x80070002), wenn ich das Install Shield ausführe, um Origin zu installieren. Was soll ich tun?

InstallShield-Error-Finish-Previous-Setup

 

Letztes Update: 12.01.2025


Wenn Sie das Origin-Installationsprogramm Setup.exe ausführen, um Origin zu installieren, Ihnen aber die folgende Fehlermeldung angezeigt wird:

Ein Fehler (-5001 : 0x80070002) ist während der Installation aufgetreten.

Bitte stellen Sie sicher, dass Sie eventuell vorhergehende Installationen abgeschlossen und andere Anwendungen geschlossen haben.
Wenn der Fehler weiterhin auftritt, wenden Sie sich bitte an Ihren Vertriebspartner:

Dieses Problem kann entstehen, wenn Sie die setup.exe aus der zip-Datei heraus ausführen, ohne sie vorher zu extrahieren.


Um dieses Problem zu beheben:

Bitte stellen Sie sicher, dass Sie die zip-Datei vollständig heruntergeladen und auf der lokalen Festplatte extrahiert haben, bevor Sie die Datei Setup.exe ausführen.

Schlüsselwörter:Installation, Setup, Install Shield, zip
