FAQ-1237 Wie kann ich die Standardlayer für Diagramme festlegen?

Set-Default-Layer-Size

Letztes Update: 26.01.2026

Wenn Sie Ihren Diagrammen eine benutzerdefinierte Layerdimension zuweisen möchten und deswegen die Einstellungen der Layergröße als ein Systemdesign speichern, stellen Sie eventuell fest, dass die Einstellungen nicht auf die neu erstellten Diagramme angewendet werden. Dies geschieht, weil der Dialog Grafiktoptionen Vorrang vor dem Systemdesign hat und Ihre design-basierten Einstellungen überschreibt.

Um Ihre benutzerdefinierte Layergröße als Standard festzulegen,

  1. wählen im Menü Einstellungen: Grafikoptionen.
  2. Gehen Sie im Dialog Grafikoptionen zur Registerkarte Layout und setzen Sie Seitenrand (%) auf Auto. Das bedeutet, dass das Systemdesign für die Layergröße (Rand) verwendet wird.
  3. Klicken Sie auf OK.

Alle neuen Diagramme erben nun die Layerabmessungen, die in Ihrem Systemdesign festgelegt sind.
