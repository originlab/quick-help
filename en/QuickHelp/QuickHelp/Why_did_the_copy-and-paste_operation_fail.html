2.143 FAQ-1239 Why did the copy-and-paste operation fail?

Copy-and-Paste-Fail

Last Update: 5/29/2026

Sometimes, the copy and paste operations might fail. This issue may be caused by certain mouse- or keyboard-related software installed by the user—such as Logitech's "Logi Options+"—that is occupying the clipboard.

Solution:

  1. Launch Origin and run the command @log=1 in the Script Window
  2. Restart Origin, try copy-and-paste operations, and check if there is any message dumped in Script Window. By reviewing these messages, identify which tool is currently occupying the clipboard.
  3. There is not any good workaround yet, you might need uninstall this tool to check if the problem persists.

Keywords:Fail to copy, paste fail, mouse and keyboard
