6.109 FAQ-1197 I get a "Lost connection to lmgrd, heartbeat timeout expired, existing. EXITING DUE TO SIGNAL 28 Exit reason 5" error. What should I do?

Lost-Connection-to-Lmgrd

Last Update: 9/5/2024

If you fail to start the FLEXnet license server, and get error message in the log file like the following:

10:38:30 (lmgrd) Lost connection to lmgrd, heartbeat timeout expired, exiting.
10:38:30 (lmgrd) Heartbeat timeout is 300 seconds. Elapsed time is 16528 seconds.
10:38:30 (lmgrd) EXITING DUE TO SIGNAL 28 Exit reason 5
10:38:30 (lmgrd) orglab exited with status 28 (Communications error)


This disconnection is probably caused by a firewall between server and clients.
To fix this problem,

Please follow this document to allow your license server access through firewall.

Note that in step 1 “At the Firewall”, when you open up specified ports, make sure you do it for every firewall that may break the connection between server and clients. For example, on the server machine, besides the Windows built-in firewall, the virus software installed on the machine may also build up another firewall. In this case, you will need to turn off monitoring for the specified ports in both firewalls.

Keywords:concurrent, -15, 10032, lmgrd is not running, Cannot connect to license server, port or hostname in the license file has been changed, EXITING DUE TO SIGNAL 28, Exit reason 5, orglab exited with status 28, Communications error, Lost connection to lmgrd, heartbeat timeout expired
