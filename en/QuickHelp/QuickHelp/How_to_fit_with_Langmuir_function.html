3.173 FAQ-1231 How to fit with the Langmuir function?

Fit-with-Langmuir-Function

Last Update: 12/22/2025

Origin provides several ways to fit the Langmuir function.

  • The Fitting Function Library app provides a ready-to-use Langmuir function. Download and install the function to fit with your data.
  • The Fit Adsorption Isotherm app provides a Langmuir Model 1 to linearize your adsorption-isotherm data, then perform linear fitting with the new dataset. This is the standard practice in Kinetics.
  • There are 3 built-in variants of Langmuir function:
    • MichaelisMenten function (Growth/Sigmoidal category), in which parameter Km = 1/Keq
    • other 2 similar functions - LangmuirEXT1 and LangmuirEXT2 (Power category).
