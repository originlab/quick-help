5.95 FAQ-1227 How to adjust the menu when it is too crowded on High DPI monitor?

Adjust-Menu-on-High-DPI

Last Update: 10/28/2025

On High DPI monitor, Origin's main menus are crowded and font size very small.

We supply two system variables to adjust gaps between menus and the font size of menu & dialog title.

  • @sfsf: Change the font size of menu & dialog title.
Default value =117. Set it to 125 to make font size bigger. Set it to 100 to the old way
  • @sfsg: Change the gap between menus.
Default value = 45. Set it to 60 to make the gap wider.

After changing the value, you need to restart Origin to see the change.
