1.178 FAQ-860 How to create a multi-panel graph by group?

Last Update: 12/7/2025

Plot-Multi-panel-Graph-by-Group

If you have data with a group column(s) (so call indexed data) and want to plot multi-panel graph by the group column(s), starting from Origin 2026, you can use the Graph Maker app.

Access it by selecting Plot > Graph Maker from the main menu. This tool uses text or categorical columns to automatically generate multiple panels arranged on a single page or across multiple pages.

Adjusting Panel Order

To modify the order of panels after plotting, do not manually rearrange them in the graph. Instead, adjust the categorical order in your worksheet:

  1. Ensure your group column is set as Categorical:
    • Origin automatically sets text-heavy columns as categorical after plotting.
    • If not set automatically, right-click the column and select Set as Categorical.
  2. Reorder categories by double-clicking the column header, Categories, (or right-click > Properties) and adjusting the order in the Categories tab. The panel order in your graph will update accordingly.


Before Origin 2026, Please refer to this blog for details.
