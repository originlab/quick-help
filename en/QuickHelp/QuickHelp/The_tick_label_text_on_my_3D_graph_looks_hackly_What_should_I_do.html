1.304 FAQ-1208 The tick label text on my 3D graph looks hackly. What should I do to improve it?

3D-Graph-Tick-Label-Anti-Aliansing

 

Last Update: 11/18/2024

If you find the text object, like tick labels in a 3D OpenGL graph looks bad, like the following,

Please first check if your graphics card meets the 3D OpenGL requirements and the driver is correctly installed and upgraded to the latest version, since the display of 3D OpenGL graphs hardly depends on the graphics card.

If everything is fine but the text is still bad, please try to set system variable @OGLF to 0. That is,

  1. Select menu Preferences: System Variables…
  2. In the Set System Variables dialog, enter “OGLF” for Variable and change its Value to 0.
