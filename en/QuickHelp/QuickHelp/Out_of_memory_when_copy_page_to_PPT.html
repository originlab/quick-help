1.192 FAQ-893 I see an "Out of Memory" error message when I copy page to PowerPoint. What is wrong?

OutOfMemory-CopyToPPT

Last Update: 6/25/2024

When you copy an Origin graph with dense data points and paste it as an Origin Graph Object (OLE object) to PowerPoint, you might get an error message:
"There isn't enough memory to perform the operation."

It is because that when you copy an Origin graph, the internal generated EMF file (saved within the PPT file) reaches the limitation of 23M.

Since it is a known issue caused by PowerPoint, it cannot be fixed from Origin side.

To workaround this problem, try one of the following solutions:

  • Use menu Edit: Copy Graph as Image instead to copy and paste the page as a picture.

or,

  • Use menu Edit:Copy Page but paste it as a picture in PowerPoint.

or,

  • Copy graph (Ctrl+C) from Origin and paste it to other Microsoft Office software like Word/Excel. It will be successfully pasted as an OLE object. Then select the OLE object and press Ctrl+C to copy it, and press Ctrl+V to paste it to PPT.
    This way the Origin graph can be pasted to PPT as an Origin object successfully.
