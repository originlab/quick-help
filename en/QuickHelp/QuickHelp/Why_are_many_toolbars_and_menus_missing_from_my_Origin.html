5.94 FAQ-1222 Why are many toolbars and menus missing from my Origin?

Menu-Missing-in-Stats-Mode

Last Update: 11/19/2025

Origin 2025b introduced a "Stats Mode" which focuses on statistical features. If you selected the option to install Stats Mode during installation (select Stats GUI radio button on "Select GUI Mode" page), Origin will be launched in Stats Mode by default. This mode hides many toolbars and menus (e.g. Peak Analyzer) from the GUI.

You can choose menu Preferences: GUI Mode: Default to return to the default interface like in previous versions.


Notes:

Preferences: Custom Menu Organizer currently doesn't work for Statistics Mode. If you have some custom menu (.omc file) and want to install in Origin 2025b, please follow steps below to modify your Origin to default mode:

  1. Close Origin if it is open.
  2. Click the Windows Start button, scroll down the app list and select OriginLab Origin 2025b | Repair or Uninstall Origin 2025b. This starts the InstallShield wizard.
  3. Select the Modify option and click Next.
  4. Click Next several times until you see the Select GUI Mode page. Select Default GUI radio button. Complete the Modify process, clicking Finish when done.

Note that the stats apps you installed before will still be availabe even if you unceck the Statistics Apps checkbox.
