1.310 FAQ-1226 How to merge the graphs without vertical or horizontal gap?

merge-graphs-without-gap

Last Update: 9/4/2025

When you merge multiple graphs into same graph windows, you might need to adjust the vertical and horizontal gap.

  • If you want to arrange these layers without any gap between adjacent axes, you can set the system variable @PFAL=0 and then set Vertial Gap or Horizontal Gap to 0 in Merge Graph Windows dialog, the layer-related and axis-related objects between the layers (such as axis tick, tick labels or axis title) will be ignored and the layer frames will be arranged without a gap.

About how to set a system variable, you can refer to this FAQ.
