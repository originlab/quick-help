1.303 FAQ-1204 Editable graph failed to be pasted on MS Powerpoint 2019, what Should I do?

Embedded-Graphs-Fail-in-PPT

Last Update: 8/19/2024


We have received reports indicating that Origin graphs cannot be embedded in MS PowerPoint 2019 using Edit: Copy Page. Only an image is pasted, and it cannot be edited by double-clicking on the graph within the PowerPoint document later.

This is a bug of MS PowerPoint 2019. Please note that when you encounter this problem, copying from Excel and pasting as an embedded object also does not work.

Upgrading your MS Office to a different version can resolve the issue
