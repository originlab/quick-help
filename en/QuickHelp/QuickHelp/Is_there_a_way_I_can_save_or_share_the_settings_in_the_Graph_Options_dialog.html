1.314 FAQ-1238 Is there a way I can save or share the settings in the Graph Options dialog?

Save-or-Share-Graph-Options-Settings

Last Update: 1/26/2026

If you assign custom settings to the Graph Options dialog (Preferences: Graph Options menu) and want to save the settings or share with others, please use GraphOptions.oth in the User Files Folder. That is,

  1. Select menu Help: Open Folder: User Files Folder.
  2. Go to the "Themes" sub-folder. Here you can find the GraphOptions.oth file saving the settings of the Graph Options dialog.
  3. To apply the same default settings on another PC, simply place/replace this GraphOptions.oth in the \User Files\Themes\ sub-folder of the target machine and restart Origin.
