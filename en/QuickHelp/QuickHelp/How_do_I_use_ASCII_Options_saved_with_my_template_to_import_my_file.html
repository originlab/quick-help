2.3 FAQ-410 How can I save ASCII import options to my template?

Save-Import-Settings

Last Update: 8/22/2024

  1. Customize ASCII Import:
    1. Select Data: Import from File: Multiple ASCII or Data: Import from File: Single ASCII (not shown in the menu by default, need to add from Data: Import from File: Add/Remove File Types... )
    2. In the ASCII dialog that opened to pick file, make sure Show Options Dialog checkbox is checked.
    3. Select your file(s) and click Open. This opens the impASC dialog box.
    4. Customize import settings as needed.
    5. click OK to import. Note that customized import settings will be saved to the target worksheet automatically (named <sheet> theme).
    6. You can do further analysis.
  2. Save Import Settings in Template
    • Select File: Save Template As..., or
    • Select File: Save Book as Analysis Template... if after importing data, some analysis and calculation is done in worksheet so there are green locks in worksheet.
  3. Import new data with customized ASCII settings.
    1. Select File: Open to load the saved template template
    2. Select Data: Import from File: Multiple ASCII or Data: Import from File: Single ASCII
    3. In the ASCII dialog, you will see <sheet> shown next to Show Options Dialog, which means there are import settings in the worksheet. If you uncheck it and import directly, the data will be imported with saved setting automatically. If you check it and click Open, the ImpASC dialog is opened with saved setting loaded. If you click the arrow button to the right of the Dialog Theme at the top of the dialog, you can verify that <sheet> theme is checked (used) by default.
