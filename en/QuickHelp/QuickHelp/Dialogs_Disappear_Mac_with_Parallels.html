5.100 FAQ-1243 Why do some dialogs disappear when running Origin on a Mac with Parallels??

Dialogs-Disappear-Mac-with-Parallels

Last Update: 10/7/2026

When running Origin on a Mac using Parallels, some dialogs may appear behind other windows and become inaccessible, making Origin appear to "freeze."

This is a known issue with window ordering (z-order) in Parallels Coherence mode and is not specific to Origin. Similar issues have been reported with other Windows applications. The problem has occurred with different Parallels releases and may reappear after updates.

Solution

Exit Coherence mode and run Windows in Window mode. The Origin dialogs should then appear normally.
