1.306 FAQ-1212 Why the mean reference line is wrong for interval plot and multi-vari graph?

mean-reference-line-wrong

Last Update: 1/22/2025

When a mean reference line is added to a interval plot or a multi-vari graph, the value of the reference line may be different from the mean value of the whole dataset.

If you meet the problem, please clear the use data within axis scale range for calculated values check box in the Reference Line tab of the Axis dialog.

With the check box is selected, the reference line will be calculated from the data in the axis scale range instead of whole dataset
