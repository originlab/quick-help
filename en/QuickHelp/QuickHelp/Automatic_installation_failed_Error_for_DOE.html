3.174 FAQ-1242 How to Fix "Automatic installation failed" Error for Design of Experiments App?

DOE-R-installation-failure

Last Update: 9/29/2026


  1. Ensure that R software is installed on your computer (recommended version: 4.4.1).
  2. Click the Design of Experiments icon in the Apps Gallery.
  3. The required packages will download automatically. If the automatic download fails, the following error message will appear in the Results Log:
  1. Open R, copy the last two lines of code from the Results Log, paste them into the R console, and press Enter to run them:
  1. A dialog window will pop up asking you to select a CRAN mirror site; select a site to initiate the package downloads in R.
  2. Once the packages have finished downloading without any error messages, restart Origin.
