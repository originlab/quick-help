5.97 FAQ-1232 How to delete multiple folders in a project?

Delete-Multi-Folder

Last Update: 12/23/2025

To delete multiple folders in a project file:

  1. In Project Explorer, right-click the empty area of the lower panel and choose Show Folders context menu.
  2. Select the root folder in the upper panel.
  3. Use Ctrl + Click (for individual items) or Shift + Click (for a contiguous range of items) to select folders you want to remove.
  4. Right-click the selection and select Delete Folders.

Keywords:delete folders, select multiple folders
